## 코드에서 남은 구체적 위험

- SEC `_entries`가 첫 unit을 선택함: USD/shares를 필드별로 명시해야 함.
- SEC duration 태그를 전체 기간에 하나 선택하므로 태그 전환 시 역사 누락 가능. 분기별 원천/태그 보존 필요.
- DART는 12월 결산 가정, 부채 계정명 단순 합산. 미매칭 부채를 0으로 처리할 수 있으며 합계/상세 중복 가능.
- ROIC/순부채도 미확인 일부 BS 항목을 0으로 처리함. 공시상 0과 수집 실패 구분 필요.
- 분기 종료일만으로는 당시 알 수 있던 데이터인지 판단 불가. 백테스트 전 공시일/정정 버전 기준 시점 제어 필요.
- 자동 발견 태그는 의미가 같은지 수동 대조 후 기업/항목 매핑에 승격해야 함.
- AI 스키마 검사는 형식·증거 참조를 확인할 뿐, 문장이 실제 근거에 부합하는지 보장하지 않음.
