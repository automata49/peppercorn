## Definition and valuation gate

- `ttm_fcf = operating_cash_flow − capex` uses **market-specific versions**, defined in `analysis/fundamentals/methods.py`: US-FCF-1 deducts the SEC acquisition line as reported (filing text must establish its exact asset scope); KR-FCF-PPE-1 deducts consolidated PPE purchases and excludes intangible purchases. A common US/KR CapEx definition is **not** a prerequisite for separate local verdicts. NVIDIA's reviewed line includes intangible assets, whereas Samsung's OpenDART mapping takes only PPE. Samsung additionally spent **1,257,544m KRW** on intangible acquisition in Q1. For that quarter, PPE-only FCF is 16,580,866 − 12,127,934 = **4,452,932m KRW**, whereas FCF including intangible purchases is **3,195,388m KRW**. Do not sort raw FCF margins into a common cross-market ranking. Show the market, method version and source line; compare within each market only when its local method and thresholds have been validated. Preserve both components when available; no silent substitution.
- `owner_earnings = FCF − SBC` in the PoC is only an SBC-adjusted proxy; it does not estimate maintenance capital spending. Samsung SBC is not collected; the value must remain unknown. Define owner earnings and ROIC invested capital/average period/tax assumptions with source-backed fixtures before Value labels.
- `market_metrics` and the Swing engine remain independent. Restatements need filing timestamps and accession history; Q2 observed data was unavailable until its 2025-08-27 filing.

## Current code changes and unclosed gates

- SEC duration tags are now selected per `(start,end)` instead of discarding history when the latest tag changes; USD and shares units are explicit. DART debt excludes breakdowns of the current portion and missing debt stays unknown. ROIC and net debt stop treating missing components as zero. Offline tests cover these failure cases.
- SEC and DART now emit `source_lineage` per computed field, listing source spans in subtraction order, units, tags/account IDs and receipt/accession identifiers; fetch also records SHA-256 of each raw response. OpenDART receipt dates are matched against the paginated official disclosure search API; missing identity/date/hash fails the recent-eight-quarter collector check. SEC companyfacts chooses the latest filed value per span; this does **not** preserve every earlier amendment in an immutable archive. The collector remains limited to December-year DART companies and does not yet independently confirm each of the last eight quarters against original filings. No production DB writes or live verdicts are implemented.
- SEC now accepts an explicit `as_of` date and filters both duration and balance-sheet inputs by filing date before selecting a value. `source_revisions` records the available filed versions of each used input span, including the amendment that supplied the selected amount. This is a reconstruction from the **current** SEC API response, not a captured historical API snapshot. Same-day tie policy: for one span, the later filing date wins, then the higher accession (its yearly sequence), independent of API response order. When another accession filed the same day reports a different amount, the collector records it in `source_conflicts` and fails the `동일자 공시 충돌 (최근 8분기)` QC check, so labels stay suppressed until a person reviews the filings; the accession order is a deterministic convention, not proof of which filing is authoritative. Agreeing duplicates are not conflicts. This has been exercised only with offline fixtures, not with live SEC data. DART historical `as_of` is deliberately rejected until immutable filing-specific responses can be archived. Market-specific thresholds remain uncalibrated.
- The ten matched values cover **one historical quarter per company**, not the last eight quarters or all balance sheet fields. Expand the independently checked official filings, including tag-switch, loss-making and alternate fiscal-year companies, before asserting phase 1 completion.
