## Definition and valuation gate

- `ttm_fcf = operating_cash_flow − capex` uses **market-specific versions**, defined in `analysis/fundamentals/methods.py`: US-FCF-1 deducts the SEC acquisition line as reported (filing text must establish its exact asset scope); KR-FCF-PPE-2 (replacing PPE-1; see the Samsung section below) deducts consolidated PPE purchases net of government grants received and excludes intangible purchases. A common US/KR CapEx definition is **not** a prerequisite for separate local verdicts. NVIDIA's reviewed line includes intangible assets, whereas Samsung's OpenDART mapping takes only PPE. Samsung additionally spent **1,257,544m KRW** on intangible acquisition in Q1. For that quarter, PPE-only FCF is 16,580,866 − 12,127,934 = **4,452,932m KRW**, whereas FCF including intangible purchases is **3,195,388m KRW**. Do not sort raw FCF margins into a common cross-market ranking. Show the market, method version and source line; compare within each market only when its local method and thresholds have been validated. Preserve both components when available; no silent substitution.
- `owner_earnings = FCF − SBC` in the PoC is only an SBC-adjusted proxy; it does not estimate maintenance capital spending. Samsung SBC is not collected; the value must remain unknown. Define owner earnings and ROIC invested capital/average period/tax assumptions with source-backed fixtures before Value labels.
- `market_metrics` and the Swing engine remain independent. Restatements need filing timestamps and accession history; Q2 observed data was unavailable until its 2025-08-27 filing.

## Current code changes and unclosed gates

- SEC duration tags are now selected per `(start,end)` instead of discarding history when the latest tag changes; USD and shares units are explicit. DART debt excludes breakdowns of the current portion and missing debt stays unknown. ROIC and net debt stop treating missing components as zero. Offline tests cover these failure cases.
- SEC and DART now emit `source_lineage` per computed field, listing source spans in subtraction order, units, tags/account IDs and receipt/accession identifiers; fetch also records SHA-256 of each raw response. OpenDART receipt dates are matched against the paginated official disclosure search API; missing identity/date/hash fails the recent-eight-quarter collector check. SEC companyfacts chooses the latest filed value per span; this does **not** preserve every earlier amendment in an immutable archive. The collector remains limited to December-year DART companies and does not yet independently confirm each of the last eight quarters against original filings. No production DB writes or live verdicts are implemented.
- SEC now accepts an explicit `as_of` date and filters both duration and balance-sheet inputs by filing date before selecting a value. `source_revisions` records the available filed versions of each used input span, including the amendment that supplied the selected amount. This is a reconstruction from the **current** SEC API response, not a captured historical API snapshot. Same-day tie policy: for one span, the later filing date wins, then the higher accession (its yearly sequence), independent of API response order. When another accession filed the same day reports a different amount, the collector records it in `source_conflicts` and fails the `동일자 공시 충돌 (최근 8분기)` QC check, so labels stay suppressed until a person reviews the filings; the accession order is a deterministic convention, not proof of which filing is authoritative. Agreeing duplicates are not conflicts. This has been exercised only with offline fixtures, not with live SEC data. DART historical `as_of` is deliberately rejected until immutable filing-specific responses can be archived. Market-specific thresholds remain uncalibrated.
- The ten matched values cover **one historical quarter per company**, not the last eight quarters or all balance sheet fields. Expand the independently checked official filings, including tag-switch, loss-making and alternate fiscal-year companies, before asserting phase 1 completion.

## Samsung reference extension and a KR CapEx basis break — 2026-09-28

Eight consecutive Samsung quarters (2024-09-30 through 2026-06-30) are now in `official_reference_2025.json`: revenue, operating income, operating cash flow, CapEx and cash for all eight, and debt for the five whose balance sheet carries all four debt lines. Values were read from Samsung's official consolidated statement PDFs by text extraction, not through a summarizer, and each row cites PDF pages. Cross-checks: the three-month revenue and operating income printed in the half-year and third-quarter statements equal the difference of their cumulative columns, and all 40 derived amounts were recomputed from the printed inputs. DART receipt numbers and filing dates were not captured (`filed` is null), so these rows are skipped whenever an `as_of` cutoff is used and are not point-in-time evidence.

**Finding: the PPE line changed basis.** Reports through the 2025 third quarter show "유형자산의 취득" net of government grants. The FY2025 annual report and the 2026 reports show it gross and present "정부보조금의 수취" as a separate investing line (FY2025 1,722,357; Q1 2026 1,586,919; H1 2026 1,592,914, KRW millions). The H1 2026 report recasts its prior-year column accordingly: H1 2025 PPE acquisition appears as 26,831,217, and 26,831,217 − 1,667,835 equals the originally reported 25,163,382. The Q1 2026 report did not recast its Q1 2025 column. Subtracting the net nine-month figure from the gross annual figure would therefore have given a fiscal Q4 2025 CapEx of 11,549,288, overstated by about 1.7 trillion KRW (the netted value is 9,826,931), and any TTM window spanning the change would mix bases.

`dart.py` now subtracts the separate grants line when a report presents it, keeps the gross amount and the grant input in the lineage, and `methods.py` moves KR to `KR-FCF-PPE-2`. A report without the line is treated as already net, and a line whose amount is blank as zero; both are assumptions that the reference gate would expose if the live account name differs from `정부보조금의 수취`. Recalculation impact: KR `capex`, `ttm_fcf`, `fcf_margin` and `owner_earnings` change for quarters from 2025-12-31 onward; earlier quarters are unchanged; no stored data or verdict exists to migrate. Any TTM FCF from `KR-FCF-PPE-1` for those quarters should be discarded.

**Also observed:** Samsung's 2026 balance sheets no longer list a bond ("사채") line although 7,134 existed at 2025-12-31. The collector's debt-continuity rule therefore reports debt as unknown for 2026 quarters, which is why 2026 rows carry no debt reference; a person should confirm the bonds were retired before that rule is relaxed. Live DART output has not been compared with these rows.
