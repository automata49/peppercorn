Read the UI and formatting section in docs/harness/CONTRACT.md. Locate the existing shared component and CSS tokens. Reproduce the affected viewport. Reuse StockRows and shared table tokens. Run npm run build and npm run test:ui. Report measured layout and behavior, not a visual guess.

Resolve paths from the Peppercorn repository root. If installed as a plugin outside Peppercorn, locate the repository first; do not apply its policies to another project.
