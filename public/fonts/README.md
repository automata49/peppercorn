# Folio Editorial Serif

Derived from Noto Serif CJK KR Regular (NotoSerifCJK-Regular.ttc, font index 1).
Source project: https://github.com/notofonts/noto-cjk/tree/main/Serif
Original copyright: © 2017–2023 Adobe.
License: SIL Open Font License 1.1, included in OFL.txt and font metadata.

Renamed to Folio Editorial Serif for this modified subset. WOFF2 retains
Latin U+0020–00FF, Hangul U+1100–11FF / U+3130–318F / U+AC00–D7A3,
and punctuation U+2000–206F / U+3000–303F. The CSS alias uses weight 400
and font-display:swap. It loads only when the classic heading role is used;
UI controls and numeric data continue using the normal Folio font stack.
